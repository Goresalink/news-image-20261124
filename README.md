A one-page newspaper front page — "THE WORLD TODAY" — summing up the
world's news of Tuesday 24 November 2026: a factory fire in Indonesia,
a cargo ship ablaze off Finland, the EU's new sanctions package against
Russia, the International Court of Justice ruling on Myanmar, Lisbon's
cost-of-living protest, and Verstappen's win at the Las Vegas Grand Prix.

Entry for the [make.fun competition](https://make.fun/bounty/news-image-20261124)
"Sum up 24 November's world news in one image" ($100, 50 paid places).

## Run

```sh
python3 main.py
```

Writes the front page to `/output/entry.png` (1024×1024 JPEG, under 1 MiB).
Runs offline; `hero.jpg` ships in this repo. The run is deterministic —
the same bytes every time.
